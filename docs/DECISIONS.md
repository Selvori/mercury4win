## D-001：以仓库文档保存持续项目信息

- 日期：2026-10-12；状态：已接受。
- 来源：用户要求确立项目信息记录机制；具体文件划分由本次任务落实。
- 决策：以 docs/README.md 导航，STATUS 保存当前概况，ISSUES 维护唯一问题状态，DECISIONS 保存长期约定，WORKLOG 追加任务事实，audits 保留历史证据。

## D-002：固定用户指定 OPML 为后续 RSS 导入样例

- 日期：2026-10-12；状态：已接受。
- 来源：用户提供 hn-popular10+1.opml 并要求作为之后导入 RSS 源的测试样例。
- 决策：按原始字节保存至 tests/fixtures/opml/hn-popular10+1.opml，记录 SHA-256 和结构预期；后续导入验收优先使用该副本。
- 理由：消除桌面绝对路径依赖，保留稳定输入并能够判断测试数据是否变化。
- 影响：样例不是 bootstrap 订阅配置；不因站点短暂失效替换地址。新增边界用例另建文件，确需修订基准时记录原因、差异和新校验值。
- 边界：固定的是 OPML 输入，远程 Feed 内容与可用性会变化；离线结构 / 去重验收与在线兼容性分开记录。详见 TESTING.md。
