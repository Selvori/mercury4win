# 分阶段 AI 主题检索

当前生产实现：`topic-search-quick100-v4`，Schema 10。旧 v4 词法候选 / 36篇流程见[历史入口](../topic_search/README.md)，其报告保留原失败和结论。

## 实际行为

- 全文搜索 → AI主题搜索 → 明确提交。先应用硬条件，再按发布时间降序/ID降序选最新100篇（无日期排后），不足100取全部。只在此范围内初筛/核验，较旧文章不进入；关键词和结果本地排序不能扩大范围。
- 主题理解的多语言词扁平OR匹配本地资料，任一词命中即先展示；标题命中权重较高，短ASCII词按词边界匹配。关键词初步匹配标为尚未AI核验，核验可添加/移除成员，确认结果优先。首个关键词结果仍需等待一次理解请求，不保证固定秒数或完整核验更快。
- 模糊/空白/合集/多主题标题、正文线索救援进入预览。标题批次的模型判断无法校验时，丢弃整批判断，将原始ID全数保留进入内容检查；界面单独显示数量，不接受陌生ID、不自动重试或缓存失败判断。预览有摘要、开头、章节标题及后部相关段落；不能依据缺少词语排除。
- 入围文章连续覆盖全部本地可用正文，5000字符一块，前200字符重叠用于上下文，重叠不重复计覆盖。各块更新文章语境并保留支持/反证，最终单独整篇判断；不自动补抓缺失正文。只有实际完整覆盖或同版本完整缓存才计全文核验。块范围由后端绑定，模型不能借回显旧块号改变实际范围。
- 缺全文可使用完整摘要或标题，但结果标明依据且不计全文。显式笔记字段才发送笔记；默认索引里的笔记线索不向模型传输。
- 一次提交自动完成有限扫描，没有36篇中断。可暂停/取消，完成阶段与正文块落库；重启后「载入上次检查」只读取本地，点击「恢复检查」才继续请求。失败保留当前初步/已确认快照，取消恢复此前范围；收起面板继续，同一查询更新保留当前阅读文章。
- 每次新结果快照使用新的不可变服务端令牌。分页/排序/批量已读不调用AI；批量作用于点击时的令牌。资料版本变化提示过期并阻止严格批量处理；新文章不进入旧快照。
- 相同主题/配置/条件/资料版本可复用分阶段缓存；正文变更不复用旧正文结论，但可复用不变标题的初筛。明确「重新理解并检查」绕过AI缓存。普通搜索/已有条件视图/专题保留；AI快照暂不能存为条件视图。

标题最多16项/约6000序列化字符，预览最多8项/22000字符，正文最多6篇各下一块/24000字符，最终最多8项/20000字符；按实际长度缩批，一篇至少一项，不以固定总token预算截断文章。Provider实际上下文/输出限制及120秒请求超时仍可能返回错误；不会自动无限重试。标题批次超时后，显式恢复按上次失败标题数减半（至少1项、最多16项），不再原样重发大批；旧64项失败检查点可直接载入。

标题、片段和最终判断均可能误判；全标题覆盖不等于全文全覆盖或零漏检。滚动文章上下文属于模型归纳，完整块与依据仍逐块保存。首次扫描通常比旧36篇流程处理更多资料，不能承诺更便宜或更快。

## 合成评估集

[基础20篇](../topic_search/corpus.json) + [11篇新增人工标注](corpus_extra.json) + `agent/staged_search/tests.rs` 中40篇自然体育/烘焙负例，共71篇，超过旧36篇边界。主题有中英文模型发布、未知型号、数据库性能、构建工具、明确日期/收藏/来源硬条件、无相关资料。

包括空标题、周刊混合内容、误导园艺/象棋标题、正文末尾及多块长文、历史引文/融资/汽车混淆、无全文但摘要可用、全空资料和不含常见AI/模型词的新名称。人工标签独立于真实模型响应。受控服务借用标签只测试协议与状态，不证明模型理解质量。

真实首轮中的数组、正文引文字符串、同篇预览的已知片段键错配及超长理由，包括空上下文null和已知块号回显错误，原始合成交换保留为 [protocol_cases.json](protocol_cases.json)。校验只允许同篇实际提供材料中的逐字引文；正文伪造引文、未知ID、重复/缺项及未知结构拒绝。预览引文无法核验时保留为不确定并进入完整资料，不能据此排除或确认相关。

## 真实 API（默认忽略）

只在明确授权后执行 [run_live.ps1](run_live.ps1)，参数 `-AppDataDirectory` 指实际路由目录，`-ReportPath` 必须新文件。仅读日常库三个AI配置表白名单及选中主模型的一份凭据；解码仅在内存，业务资料全部来自合成内存库，不写日常库，不读取其文章/笔记。

每次请求前后追加并同步落盘JSONL，请求前校验完整用量SQL和报告可写性；失败/超时的未知用量保留未知。无备用路由或自动重试。`M4W_STAGED_ALLOWANCE` 控制实验请求上限（最多160），不是产品预算；`M4W_STAGED_SKIP_BASELINE=1` 可复用同一固定语料/模型已完成的旧基线，避免重复付费。完整评估必须使用固定七例；定向修复不得冒充整套通过。`M4W_STAGED_REPLAY_REPORT` 可在逐项system/user输入相同（理解阶段当前时刻除外）的条件下回放已完成的真实合成响应，恢复测试检查点，仅为原未完成例补发请求；回放数量与新增HTTP/用量独立记录，含回放的耗时不可当首次扫描性能。

旧对照按相同71篇硬范围开始，继续到旧算法自身的词法候选池耗尽；分别报告其实际候选数、首结果和完整时间及用量，不能把不同正文覆盖当成成本优势。

## 隔离原生复验

`seed_native.py` 只接受已核对无AI配置/用量的V5种子，目标必须新文件。使用独立Tauri identifier、应用目录、合成71篇及18763 loopback服务；不得复制日常库/凭据。`native_provider.py` 只响应本地受控协议，不转发。

实际验收应覆盖一次提交完成71标题、多块/仅摘要标记、暂停HTTP、关闭重启载入/恢复、正文中途失败与三篇部分快照、恢复到12篇、排序/批量只使用旧令牌、普通视图保存及英文暗色800×600。退出后核对合成库、无笔记外发、无密钥文件、外键及请求事实；停止本任务拥有的进程并清理CU会话。完整检查与失败见对应 `docs/audits/staged-search-*` 报告，不能以受控结果替代真实模型质量。

本次实际结果见[真实模型/回放补齐报告](../../docs/audits/staged-search-live-2026-10-28.md)和[隔离桌面报告](../../docs/audits/staged-search-native-2026-10-28.md)。
